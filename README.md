# CaseNotes

A local-first notes app for iOS built with Swift and SwiftUI.

CaseNotes is a project for exploring native iOS development while building a
practical notes application focused on simple organization and local storage.

## Planned Features

- Create, edit, and delete notes
- Local persistence
- Search and sorting
- Tags and pinned notes
- Optional event dates
- Face ID / device authentication
- Markdown or text export

## Tech

- Swift
- SwiftUI
- Xcode

## Status

Early development.

## Privacy

CaseNotes is designed around local-first storage. The repository contains only
application source code and synthetic development data, never personal notes.
